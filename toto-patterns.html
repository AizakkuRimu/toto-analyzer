Deterministic 7-Draw Scoring

The Scoreboard

Every number 1–49 is scored across six rules run only over the last 7 draws (plus one extra older draw for a single punishment check): a row-by-row survival trail, kinship bonuses between numbers, an ascension/punishment pass, and a ghost-number cleanup. The 7 highest-scoring numbers at the end are the pick for the next draw.

The 7-Draw Window

The oldest of the seven is Draw 1, the most recent is Draw 7 ("the last draw"). One extra older draw ("Draw 0" / the 8th most-recent draw) is shown too — it is used only for the Step 5 punishment check, never for anything else.

① Survival Trail

Walking row by row from Draw 1 to Draw 7, every number is tracked for whether it carried over, dropped out, came back, or showed up for the first time.

+1 survives into the next row it appears in again  ·  −3 falls off the row after it stops appearing  ·  +2 revives after having fallen off earlier  ·  +1 totally new the first time it ever appears in the window

② Kinship Bonuses

Every number that appeared anywhere across the 7 draws is checked against every other such number for shared traits. Each qualifying relationship is worth a flat +1 — a number can rack up more than one.

+1 shares a front digit with another number in the pool  ·  +1 shares a back digit  ·  +1 is the digit-flip of another number in the pool  ·  +1 per number inside a run of neighbouring (consecutive) numbers, e.g. 44‑45‑46 gives each of those three +1

③ Ascension & Punishment

Draws 1–6 (everything except the last draw itself) are each stretched into their sorted 7-star chain, and every run of 3, 4, 5 and 6 consecutive stars in that chain is logged as an "ascension". A number scores for every ascension it appears in from a different draw than the one currently being judged — the last draw's own numbers can't score off their own chain. Separately, every number from the extra 8th (pre-window) draw is checked against the whole 7-draw window: if it never reappeared there, it's punished.

+1 per 3-run  ·  +2 per 4-run  ·  +3 per 5-run  ·  +4 per 6-run it belongs to (all cumulative across draws 1–6)  ·  −1 flat if a number appears in none of those ascensions at all.
Punishment: every number in the extra 8th (pre-window) draw that did not reappear anywhere across the 7-draw window takes a −1.

Every other number (not shown above) never appeared across draws 1–6 at all, so it takes the flat −1 for this step.

④ Ghost Numbers

Numbers that didn't appear anywhere at all across all 7 draws. Normally that's a flat −1 — but if either neighbour (n−1 or n+1) is sitting in the provisional top 5 (steps 1–3 rank + kinship + step 5 combined, before this step), the ghost gets a vote of confidence instead: +2.
